# Парсер цен для Excel-прайс-листа

Скрипт обновляет цены в Excel-прайс-листе, автоматически заходя по ссылкам
на сайты поставщиков и вытаскивая оттуда актуальную цену товара.

## Требования

- Python 3.9+
- Установленный Google Chrome (нужен для парсинга bestly.ru через Selenium —
  драйвер под вашу версию Chrome скрипт подтягивает сам через
  `webdriver-manager`, саму программу Chrome нужно поставить вручную)

## Установка

```bash
pip install -r requirements.txt
```

Рекомендуется ставить в отдельное виртуальное окружение:

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# или: source venv/bin/activate   # Linux/macOS
pip install -r requirements.txt
```

## Запуск

```bash
python price_parser_sheets.py
```

По умолчанию скрипт ищет файл `Цены на материалы(автоматические).xlsx` в
текущей папке. Если у вас прайс-лист называется иначе или лежит в другом
месте — есть два варианта:

**1. Передать путь аргументом командной строки** (удобно для регулярных
запусков/скриптов):

```bash
python price_parser_sheets.py --file "мой_прайс.xlsx"
python price_parser_sheets.py --file "мой_прайс.xlsx" --sheet "Прайс-лист 2024"
```

**2. Ничего не передавать** — если файла по умолчанию нет, скрипт сам
спросит путь при запуске:

```
Файл 'Цены на материалы(автоматические).xlsx' не найден.
Введите путь к вашему Excel-файлу прайс-листа (Enter — отмена):
```

## Требования к структуре Excel-файла

На листе (по умолчанию он называется «Прайс-лист», можно указать своё имя
через `--sheet`) должны быть колонки:

| Колонка | Обязательна | Назначение |
|---|---|---|
| Название | да | Название товара — используется для поиска нужной цены на странице (толщина, размер, цвет и т.д. извлекаются прямо из названия) |
| URL | да | Ссылка на товар у поставщика |
| Цена | нет, заполняется скриптом | Текущая/найденная цена |
| Селектор | нет | CSS-селектор элемента с ценой — если пустой, скрипт попробует найти его сам и сохранит на будущее |
| Характеристика | нет, заполняется скриптом | Доп. сведения о товаре, если их удалось определить на странице |
| Дата обновления | нет, заполняется скриптом | Когда цена была найдена в последний раз |

Остальные колонки (например, расход на м², наценка и т.п.) скрипт не
трогает.

## Меню

После запуска откроется интерактивное меню:

1. Запустить парсинг всех товаров
2. Запустить парсинг начиная с конкретной позиции
3. Найти и выбрать селектор цены для конкретного товара вручную
4. Протестировать уже сохранённый селектор для товара
5. Проверить, что Selenium/Chrome работает
6. Протестировать универсальный парсер таблиц (для bestly.ru)
7. Найти/отредактировать товар или добавить новый
8. Просмотреть статистику по сайтам
9. Принудительно перезаписать все селекторы и характеристики в Excel
10. Просмотреть и при необходимости удалить сохранённые вручную выборы селекторов
11. Выход

Почти везде можно отменить действие, просто нажав Enter.

## Файлы, которые скрипт создаёт сам

Все перечисленные ниже файлы создаются рядом со скриптом при первом
запуске и **не относятся к репозиторию** — они личные для каждого
компьютера/пользователя (добавлены в `.gitignore`):

- **`site_configs.json`** — настройки сайтов-поставщиков (заголовки
  запроса, CSS-селекторы цены). Создаётся из встроенных значений по
  умолчанию. Чтобы добавить новый сайт или поправить селектор — просто
  отредактируйте этот файл, перезапуск с правкой кода не требуется.
- **`user_selections.json`** — селекторы, которые вы один раз выбрали
  вручную через пункт меню 3; при следующих запусках используются
  автоматически.
- **`price_parser.log`** — подробный лог работы (с ротацией, не растёт
  бесконечно).
- **`report_parsing_YYYYMMDD_HHMMSS.txt`** — отчёт по итогам каждого
  запуска парсинга всех товаров: что нашлось, что нет, и отдельным
  блоком — подозрительные скачки цены (когда цена изменилась вдвое и
  сильнее — стоит перепроверить вручную, не взята ли цена другого
  товара/варианта).

## Режим округления цены

По умолчанию цены округляются вверх до целого рубля. Поменять режим —
пункт меню "Настройка режима округления" (там же описаны все варианты).

## Добавление нового сайта-поставщика

Откройте `site_configs.json` и добавьте домен по образцу уже имеющихся:

```json
"example.com": {
  "name": "Example",
  "method": "requests",
  "headers": {
    "User-Agent": "Mozilla/5.0 ..."
  },
  "price_selectors": [
    ".price-current"
  ]
}
```

`price_selectors` — список CSS-селекторов, которые скрипт пробует по
очереди. Если ни один не сработает, он всё равно попробует найти цену
эвристически по названию товара на странице.

Если сайт сильно зависит от JavaScript (цена подгружается динамически),
укажите `"method": "selenium"` — но учтите, что Selenium работает заметно
медленнее `requests`.
